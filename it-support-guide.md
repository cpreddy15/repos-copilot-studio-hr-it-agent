# IT Support Guide (Sample — Fictional Company "Contoso")

## Password Reset
Use the self-service password reset portal. You'll need your registered mobile number or authenticator app. Passwords must be at least 12 characters.

## VPN
Install the corporate VPN client from the Company Portal. If the connection drops repeatedly, restart the client, check your internet connection, and raise a ticket if the issue continues.

## New Software Requests
Request software through the Company Portal. Licensed software requires manager approval.

## Contact IT
Raise a ticket via the HR & IT Helpdesk agent in Teams, or email it-helpdesk@contoso.example.
